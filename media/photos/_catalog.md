# Photo catalog

Working notes for the Photos page. Description + aspect ratio (`· AR`) for every image in
`media/photos/`, grouped into candidate series. **Order is not decided yet** — this is
just the inventory and proposed groupings.

Each file also has a `-small` version (max 640px). Click-through on the site should
open the **full** version.

Aspect ratio: photos close to 3:2 or 2:3 are snapped to **1.50** / **0.67**; the rest keep
their true ratio — **cctv 2.04** (wide), **palm-silhouette 1.00** (square), and the taller
portraits **basilica 0.56**, **bridge-moon 0.76**, **aquarium-portrait / bridge-night /
spain-flag-moon 0.80**. Only one native 0.67 (green-portrait), so most narrow-column slots
would crop a 1.50 to 2:3 (fine via object-fit, but a tight crop).

`fairy-small-alt.jpg` is a stray 150×100 thumbnail — **recommend deleting.**
